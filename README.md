# Interactive Game Research & Moodboard

- 维护人：待登记
- 来源：互动营销游戏研究与视觉参考交付需求
- 所属业务域：互动域
- 当前状态：待评审

## 用途

将互动营销游戏的竞品案例、用户反馈、官方视觉趋势和视觉参考整合为可追溯的中文 HTML 调研与参考板，支持设计决策。

## 适用场景

适用于抽奖、答题、收集、养成、任务、关卡、合成、品牌 H5、小程序游戏和增长游戏化。普通品牌视觉或非互动活动页面不适用。

## 输入

项目名称和背景、玩法或“暂不确定”、业务目标、目标受众；可选补充 PRD、链接、截图、已有研究资料与阶段限制。

## 输出

1. `interactive-game-research-<project-slug>.html`：竞品调研与用户反馈证据板。
2. `interactive-game-visual-reference-<project-slug>.html`：经确认方向的视觉参考板。
3. 审计所需的来源链接、截图、日期、限制与素材清单。

## 依赖资料

- 小红书站内公开可见内容与用户已登录会话
- Pinterest Predicts、Canva Design Trends、Adobe Creative Trends Report
- `references/` 内的规则、流程与小红书搜索协议

## 边界和风险

不绕过登录、验证码或访问控制；不伪造帖子、互动指标、评论、来源或截图。方向与视觉参考采集需经过相应确认节点。引用素材默认仅用于研究、内部对齐或本地归档，复用前需另行确认权利。
