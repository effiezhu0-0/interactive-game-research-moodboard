## Interactive Game Research & Moodboard

### 基础信息

提交人：朱若焉

维护人：朱若焉

来源：自行开发

所属业务域：互动域

当前状态：已应用 v1.1

### Skill 目标

- **设计归因**：将竞品案例、用户反馈与可见视觉信号对应到业务目标、玩法机制、留存触发与情绪价值，避免仅凭主观偏好提出设计判断。
- **方向收敛**：在用户确认的证据和官方视觉趋势基础上形成三个可讨论、可选择的视觉方向。
- **参考落地**：从原始详情页筛选去重的视觉参考，支持后续界面、动效、奖励与成长体验的设计执行。

### 用途

将互动营销游戏的竞品案例、用户反馈、视觉趋势和视觉参考整合为可追溯的调研报告与情绪板，启发并支撑设计决策。

### 适用场景

适用于抽奖、答题、收集、养成、任务、关卡、合成、品牌 H5、小程序游戏和增长游戏化。普通品牌视觉或非互动活动页面不适用。

### 输入

项目名称和背景、玩法或“暂不确定”、可选输入业务目标、目标受众、补充 PRD、链接、截图、已有研究资料与阶段限制。

### 输出

1. `competitor-research-<project-slug>.html`：竞品调研与用户反馈证据板。
2. `moodboard-<project-slug>.html`：经确认方向的视觉参考板。
3. 审计所需的来源链接、截图、日期、限制与素材清单。

### 依赖资料

- 小红书站内公开可见内容与用户已登录会话
- Pinterest Predicts、Canva Design Trends、Adobe Creative Trends Report
- `references/` 内的规则、流程与小红书搜索协议

### 边界和风险

不绕过登录、验证码或访问控制；不伪造帖子、互动指标、评论、来源或截图。方向与视觉参考采集需经过相应确认节点。引用素材默认仅用于研究、内部对齐或本地归档，复用前需另行确认权利。
