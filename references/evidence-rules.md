# 核心规则

## 来源与访问

- 以小红书站内搜索为主要研究来源。除非用户明确要求扩展，不使用普通网页搜索或其他平台替代。
- 使用用户已登录的浏览器会话，不索取密码、Cookie、Token 或其他凭据。
- 遇到登录、验证码、挑战或搜索阻断时停止自动操作，请用户处理后再继续。

## 证据准入

- 仅记录页面可见信息；不确定值标注为“未显示”“不可见”或“约”。
- 每条重要结论必须由证据截图、来源链接及可见文本或指标支撑。
- 默认仅保留可见互动量大于 50 的相关内容；排除无关旅行日记、泛 JOY 内容及非目标活动。
- 帖子详情截图必须覆盖完整媒体区、正文/作者区、可见指标和评论区；截图裁切错误、内容不可读或来源无法归属时必须重采。
- 评论用于结论时，按顺序截取并保留重叠区域；未完全加载时标明停止位置。

## 分析边界

- 主分析结构固定为：达成的业务目标、游戏玩法模式、用户牵引及留存机制、内容叙事与情绪价值。
- 区分直接观察和推断，不把单一帖子扩展成未经支持的市场结论。
- 候选证据须先交由用户确认；未确认前不生成最终分析，除非用户明确要求跳过审核。

## 交付与写入

- 默认只生成可视化 HTML 报告。
- PNG 与 PDF 仅作为可选导出，用户明确选择后再生成。
- 用户确认报告并明确指定目标后，才写入 Relay/Zero 或 Figma。
- 设计稿写入必须保留可编辑结构，使用原始证据截图并完成视觉验收；不得用模糊占位图或压缩后的整页截图替代证据。

## 禁止事项

- 不绕过平台登录、验证或访问控制。
- 不伪造互动数据、评论、来源链接、用户原话或截图。
- 不用截图中的私人信息做与研究目的无关的识别、推断或扩散。
- 不在用户未确认时向外部系统写入最终报告。
