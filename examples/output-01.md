# 示例输出

# 调研交付完成

已完成竞品、用户反馈、官方趋势与视觉参考采集，并在确认节点后生成两份本地 HTML 交付物。

## 用户反馈与竞品调研 HTML

- 包含项目背景、竞品案例、用户反馈、四维分析矩阵、证据截图、来源、日期与限制说明。
- 竞品与用户反馈证据可追溯；原帖无法稳定访问时，保留对应的小红书搜索页链接。

## 视觉参考 HTML

- 包含三个已确认方向。
- 每个方向各 10 张去重的原始视觉参考图。
- 单张图片下仅保留来源与可见日期。

## 验收记录

- 已完成证据确认与方向确认。
- 参考图来自原始详情页，未使用搜索缩略图或浏览器界面截图。
- 可见日期缺失时标注“日期未显示”。
- 参考素材仅用于研究、内部对齐或本地归档；对外复用前需确认授权。
